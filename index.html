Công cụ hoạt động như thế nào?
  1. Trích xuất EXIF & GPS ngay tại trình duyệt: Khi bạn chọn ảnh, công cụ sử dụng thư viện xử lý metadata để đọc thông tin thiết bị (iPhone, Canon, Sony...), khẩu độ, tiêu cự, ISO và toạ độ GPS.
  2. Tự động Reverse Geocoding: Toạ độ GPS lập tức được chuyển đổi thành tên địa danh thực tế (phường, quận, thành phố, quốc gia) qua dịch vụ bản đồ mã nguồn mở miễn phí.
  3. Lưu trữ Google Drive an toàn: Dữ liệu ảnh và thông tin địa điểm được tải thẳng lên thư mục riêng trên tài khoản Google Drive của bạn (scope drive.file), không đi qua bất kỳ server trung gian nào.
  4. Tạo link nhúng 1-click: Nhận ngay direct link ảnh, cú pháp Markdown hoặc HTML tag để dán vào bài viết blog, portfolio hay tài liệu.

Cấu hình kết nối Google Drive

Kết nối trực tiếp tài khoản Google của bạn bằng OAuth 2.0. Ảnh và dữ liệu sẽ được lưu an toàn trong thư mục riêng trên Drive của bạn.

Tạo miễn phí trong 1 phút tại Google Cloud Console (xem hướng dẫn bên dưới).
Cách lấy Client ID miễn phí:
  1. Vào Google Cloud Console > Tạo dự án mới.
  2. Vào APIs & Services > Enable Google Drive API.
  3. Vào Credentials > Create Credentials > OAuth client ID.
  4. Chọn Application type: Web application.
  5. Bấm + ADD URI (Thêm URI) tại mục Authorized JavaScript origins và thêm đủ 3 dòng riêng biệt (không để dấu / ở cuối):
    • https://hoangpham.is-a.dev
    • http://localhost:3000
    • http://localhost:8000
  6. Copy Client ID dán vào ô bên trên và bấm Kết nối!
